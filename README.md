# Flit

Flit is a customizable RSS reader, with support for podcasts, youtube, Twitter/X and bluesky.


## Features

- Custom theme colors
- Dark & Light mode
- Multiple sources
- Sort by priority
- Bookmark your favorites
## Tech Stack

**Framework:** Tauri, with html, css, js & rust
